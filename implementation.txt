# Implementation Plan - Multi-file, Folder, and ZIP Upload

This plan outlines the steps to add support for batch document classification in the Weaviate classifier. Users will be able to upload multiple files at once, select entire folders, or upload ZIP archives for processing.

## User Review Required

> [!IMPORTANT]
> **Processing Time**: Batch processing multiple documents (especially via OCR) can be time-consuming. We will process files sequentially on the server to manage memory and CPU load, but the UI will show a progress indicator for the entire batch.

> [!NOTE]
> **ZIP Structure**: For ZIP uploads, we will recursively search for supported file types (`.pdf`, `.jpg`, `.jpeg`, `.png`) within all nested folders.

## Proposed Changes

### Backend

---

#### [MODIFY] [views.py](file:///c:/Users/HP/Pictures/doc_classifier/weaviate_classifier/views.py)
- Implement `classify_batch` view:
    - Extract files from `request.FILES.getlist('files')`.
    - Handle ZIP extraction to a temporary directory.
    - Recursively collect all supported files from the uploaded set.
    - For each file, perform OCR then classify using `hybrid_classifier`.
    - Return a list of results: `[{ filename, document_type, confidence, ... }]`.
- Refactor single-file classification logic into a helper function `_process_single_file` to reduce duplication.

#### [MODIFY] [urls.py](file:///c:/Users/HP/Pictures/doc_classifier/weaviate_classifier/urls.py)
- Register `path('classify-batch/', views.classify_batch, name='classify_batch')`.

### Frontend

---

#### [MODIFY] [index.html](file:///c:/Users/HP/Pictures/doc_classifier/weaviate_classifier/templates/weaviate_classifier/index.html)
- **UI Updates**:
    - Update the "Classify" tab drop zone `<input>` to have `multiple` and `webkitdirectory` attributes.
    - Add a "Batch Mode" toggle or summary view to display a list of all uploaded files before/during processing.
    - Add a "Batch Results" section (table) that appears when multiple files are processed.
- **JS Logic**:

    - Show individual status (pending/processing/done) for each file in the batch.

    - Enable clicking a result in the summary table to view its full details (OCR text, top matches) in the main result card.
